Este proyecto implicaba realizar consultar para obtener información de las tablas cargadas en la anterior entrega.
A través de estas se pudo no solo obtener un resumen ejecutivo donde se visualizaban las ventas del mes (Marzo), aplicándose las funciones de agregación correspondientes y agrupándolas con la consulta de MONTH y su GROUP BY.
También se hicieron otras consultas: por un lado para tener los productos mas vendidos (llegando al resultado de que no todos se vendían de igual manera ni facturaban lo mismo). Por otro lado cuanto compraban cada uno de los clientes, teniendo todos la misma cantidad pero distinto nivel de gasto. También llegando a ella a través de las funciones de agregación pero esta vez utilizando el HAVING ya que implicaba a grupos.
Y por ultimo se aplicó una subconsulta  junto a una CTE. Esta compara la facturación de cada producto con el promedio de facturación total, y la ubica por encima o debajo de ese promedio para una mayor precisión en la toma de decisiones a futuro. Primero se limpiaron los datos y preparó la tabla, para luego consumirla/consultar y aplicar los CASE en función el valor que arrojaba dicho numero.
